# LiveNotes 1.0.2

修复快速课堂语音中，临时识别结果被最终结果修正后仍残留、导致字幕重复的问题。保留能够定位的未完成后半句和实际重复说出的内容；停止保存不会再混入已被替换的粗略假设。

- 修复低音量但仍在转写时的状态文案。
- 修复结束保存按钮在背景窗口中的文字对比度。
- 用不可变界面快照读取实时字幕，避免 XCUITest 在预览提交时发生竞态；测试失败也会结束音频播放。
- 移除没有生产调用的旧字幕缓冲、预览和回退策略。

验证使用 5618、5047 真实课程录音，包含 1.25× / 1.5× 原生事件回放，以及 1.25× 扬声器播放→麦克风录音的 XCUITest、录屏和逐帧分析。清理后的 98 项核心测试和实际发布包的 42 项 XCUITest 全部通过，发布校验通过。完整记录见 [验证报告](../validation-2026-09-14.md)。

这次修复针对应用额外制造的重复，不代表原生语音识别已达到课堂逐字准确率。5047 快速远场录音仍有明显术语错识别，例如 iPhone；这项限制在测试中保留记录。原音频和桌面录像只留在本机，不作为公开发布附件。

本版沿用 preview 分发方式：ad hoc 签名，尚未使用 Developer ID 签名或公证。
