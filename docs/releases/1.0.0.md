# LiveNotes 1.0.0

LiveNotes records locally, displays English transcription and Chinese translation, and exports the recording with the current transcript.

## Changes

- Preserve earlier sentences when live recognition revises a phrase, including shorter corrections and fragments within the same displayed second.
- Keep corrected final text from being overwritten or duplicated by an older speech draft.
- Finish recording by saving the live transcript, its trailing words, and translations already available. Normal save no longer starts another full-recording transcription pass or waits for missing translations.
- Export the current Markdown transcript and original audio in the background. Incomplete translation does not block export, and a failed replacement preserves the previous exported files.
- Start speech recognition before microphone capture and retain buffered text received around pause and stop.

Recording, speech recognition, and translation continue to use Apple-native APIs. Speech and translation accuracy still depend on Apple's models. See the [microphone and transcript validation report](../validation-2026-09-05.md) for measured results and limitations.

## Install or update

```bash
brew install yongyaoduan/livenotes/livenotes
```

For an existing installation:

```bash
brew update
brew upgrade --cask yongyaoduan/livenotes/livenotes
```

Requires an Apple Silicon Mac with macOS 26 or newer. Low-latency translation requires macOS 26.4 or newer and installed translation assets. Existing saved recordings and transcripts remain compatible.

This build uses the project's existing preview distribution channel and is not Developer ID signed or notarized. If macOS blocks launch, open System Settings > Privacy & Security and choose Open Anyway.
